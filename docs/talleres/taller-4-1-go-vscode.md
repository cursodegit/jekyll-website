## Realizar copia de seguridad

Usando el explorador de `Windows`, abrimos la carpeta que contiene nuestro proyecto:

![Eclipse workspace]({% link assets/img/talleres/go/taller-4-1-carpeta-mystuff.png %})


Cerramos `Visual Studio Code` y hacemos clic con el botó derecho sobre la carpeta `github-client`.
Seleccionamos la opción *Comprimir A -> Archivo ZIP*:

![Coprimir proyecto]({% link assets/img/talleres/go/taller-4-1-comprimir-proyecto.png %})

Moveremos el fichero `zip` resultante a nuestra carpeta de usuario. Lo necesitaremos más tarde para restaurar el repositorio.
